# Audit history

Workspace admins can open Audit in a workspace. Superadmins can also open the
global Audit Log from the main navigation.

Choose an entity type, action or date to update the history immediately. Agent
Sessions shows session lifecycle events; Session task connections shows new task
links. Clear Filters appears while a constraint is set and restores the unfiltered
history within the current workspace or global view.

Select an event to inspect its recorded values. Load more continues the current
query. A failed query shows an error instead of an empty-history message.

Use an entity's underlined text to open its current destination. The surrounding
row space selects the event. Session connections offer separate session and task
links; dependencies offer separate owning-task and dependency-task links.

Back to Audit returns to the original filters, selected event and scroll position.
Unavailable or unsupported destinations are identified explicitly; their recorded
audit values remain available for inspection. See the [destination contract](../reference/audit-navigation.md).
