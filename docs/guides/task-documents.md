# Task Sources and Evidence

Open **Details** on a task card. **Sources** shows the documents people have attached for the task. **Evidence** shows the documents and completed agent sessions linked as evidence. Its total covers all pages, so it can be larger than the number of entries on screen.

## Upload and remove Sources

1. Open **Sources** and choose **Upload source**. Workspace edit access is required.
2. Select a file up to 25 MiB. Add a title if you want the card to show a different label from the filename.
3. Submit the upload. If the transfer fails, retry in the same dialog with the same file and title.

You can upload to a completed task. Use **Remove from Sources** to remove its Source link. If the document also appears in **Document evidence**, it stays available there.

Document evidence is added through MCP. The browser provides preview and download controls for both roles.

## Preview and download

Use an image or video thumbnail or the document’s **Preview** button to open the preview. Use **Zoom** and **Fit** for raster previews and the page controls for PDFs. Animated images and supported MP4 files with one H.264 video track show a static first frame. Download the original MP4 to play it. Styled HTML opens in an isolated frame.

The original remains available through **↓ Download** while a preview is queued, processing or unavailable. To preview an unsupported format, export it as PNG or PDF and upload that file. A failed preview can show **Retry preview** when another attempt is available and you have edit access.

Use **Close** to dismiss a preview and return to the opening control. In a styled HTML preview, Tab and Shift+Tab can take you back to the app controls. Escape closes the dialog while an app control has focus.

Under **Agent sessions**, the existing session download controls are separate from document downloads. **↓ Download all** there saves the task’s session evidence ZIP.
